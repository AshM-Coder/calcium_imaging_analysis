# Data

- `coord_file3_ch1.npy`, `coord_file3_ch2.npy` — x/y coordinates of imaged neurons in each channel. Small, included in this repo.
- `DFF_file3_ch1.npy`, `DFF_file3_ch2.npy` — ΔF/F fluorescence time series for each channel (~90 MB each). **Not included** in this repo to keep it lightweight and avoid storing large binary files in git.

To run the notebook, place `DFF_file3_ch1.npy` and `DFF_file3_ch2.npy` in this folder. They can be obtained from the original dataset (Yu et al., 2021) at figshare: https://doi.org/10.6084/m9.figshare.15163914, or from wherever you originally received the coursework data files.
